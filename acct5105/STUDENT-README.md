## This course is one project

You design a community money, issue it on the **class testnet**, and show it circulating. The PDFs are how we see the design — not a second class.

Every assignment page starts with **in one sentence**, **what to turn in**, and **where to look if stuck**.

## Hard rules

- Testnet only. No real money. No public sale.
- Never put a seed phrase in a PDF or a chat.
- Labs: you may talk; written answers must be yours.

Python for labs: follow [`site/setup.html`](site/setup.html) (Jupyter page), or `pip install -r requirements.txt` then open Jupyter. Never paste a seed into a notebook.
