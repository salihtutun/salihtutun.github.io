If you have never studied this

You do not need a finance background or a crypto wallet history. The course uses cafeteria punches, house keys, and a lemonade bowl. Read the plain-English page, then type in the notebook with us.

Start here: the ideas in plain English Words we refuse to mix (pay, sit, price) Missed-class handbook
If this is newWhat it is, in one line
MoneySomething that can pay (spend now), sit (save for later), and price (the yardstick on the tag). A punch is a meal credit, not a fist.
LedgerA list of who has what. A payment is two updates: sender down and receiver up.
Hash / signatureFingerprint of the bag / “I approved this.” Not a secret code.
Address / seedLocker number (public) / house key (never on a screen).
Block / nonceA page in the notebook / the guess counter until the fingerprint looks rare.
Price / index / betaRight now / a playlist / a dance partner in the data, not a seatbelt.
