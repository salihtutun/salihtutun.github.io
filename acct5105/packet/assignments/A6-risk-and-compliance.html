Part 1: Risk (use L3 + the class AMM)

  1. Label three risks from this list: market, liquidity, admin key, oracle, custody, contagion.
  2. What you saw in class when CLASSUSD was scarce or a pool was thin. If it was not your pool, write as an observer. Numbers beat vibes.
  3. Three kill criteria in if-then form with a number. Example shape (steal structure, not the dorm story):
  • IF |\mathrm{price}-\mathrm{peg}|/\mathrm{peg} > 0.40 AND depth < 50 CLASSUSD THEN pause transfers.
  • IF freezer / redemption inventory < N THEN stop honoring and post the run price.
  • IF a booked redemption is not honored within 24 hours THEN pause mint and log make-good.
  1. One mitigation you actually own: a pause button you coded, a second pauser from A2, or a treasury procedure you would run. Do not list tools you did not implement.

Peg / run / pause in one breath. Peg = the poster. Run = the Saturday crowd at one door. Pause = freeze transfers. Pause does not print scoops.
