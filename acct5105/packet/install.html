ACCT 5105-01 - Financial Reporting & Assurance in a Blockchain World

Open Jupyter in 15 minutes

Done when the Session 1 Demo of three jobs prints four lines (concert_ticket -> exchange, and so on). Then stop. You do not need MetaMask today.

Use the folder that contains requirements.txt (the student files).

1. Python 3

You need Python 3.10 or newer.

Windows. Install from python.org (tick “Add python.exe to PATH”) or the Microsoft Store. In PowerShell:

py --version

Mac / Linux. In Terminal:

python3 --version

If that fails, install Python first, then come back.

2. Get the files

Either clone:

git clone https://github.com/salihtutun/intro-to-blockchain-and-cryptocurrency.git

or download the ZIP from that GitHub page and unzip it. Then open a terminal inside the cloned/unzipped folder (the one with requirements.txt).

3. Install the course packages

Windows (PowerShell):

py -m pip install -r requirements.txt

Mac / Linux:

python3 -m pip install -r requirements.txt

Wait until it finishes. You only do this once (or when we change requirements.txt).

4. Open Session 1

Windows:

py -m jupyter notebook notebooks/sessions/S01_community_money.ipynb

Mac / Linux:

python3 -m jupyter notebook notebooks/sessions/S01_community_money.ipynb

A browser tab should open. Cursor or VS Code also works: File → Open the same .ipynb.

Pick the Python 3 kernel if it asks.

5. Run the first Demo

Find the cell that starts # Demo — three jobs. Click it. Run it (the play button, or Shift+Enter).

You should see four job labels, then A token with no job is a sticker.

That is the whole check. In class we run the rest together.

??? in YOUR TURN cells is on purpose. Those will not run until you type.

If it breaks

What you seeTry
python / py not foundReinstall Python and tick PATH (Windows), then open a new terminal
No module named jupyterYou are not in the folder with requirements.txt, or pip went to a different Python. Run the pip install line again with py -m / python3 -m
Notebook opens but will not runKernel menu → Python 3. Not “Julia” or an empty kernel
Plots fail later (L1–L3)matplotlib is in requirements.txt. Re-run the install line

Do not paste a seed phrase, a private key, or a mainnet address into any notebook.
