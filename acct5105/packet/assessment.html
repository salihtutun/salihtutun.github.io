What you will turn in

This course is one project: design a community money, issue it on the class testnet, and show it circulating. The PDFs exist so we can see the design. They are not a second course.

If a word feels hard: open Start here first (no finance or blockchain required). Then re-run that session’s Demo cells, read Keep this straight, then open handbook.html (cafeteria / house-key / lemonade pictures). Each class has its own page under sessions/ (S1–S13) plus a practice notebook. Every class notebook starts with Words we use today and ends with Check you understand. If you can explain the picture to a sharp 15-year-old, you understand it. If you can only say “decentralized,” open Start here before you write.
