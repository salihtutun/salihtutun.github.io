L3 — Peg, Saturday rush, kill switch (due end of Module 6)

In one sentence. Run our peg notebook: a real stablecoin if the network allows it, the class gift-card rush, then two numbered kill rules for your coin.

DueEnd of Module 6 (with A6)
WhoIndividual
TimeAbout 60–75 minutes
Turn inPDF + L3-depeg.png + L3-ourcoin.png from notebooks/labs/lab_output/
Points20 (one-third of the 20% lab bucket)

Stuck? Handbook → Session 11 (gift-card / freezer). Copy the Q5 lines into A6.

You will actually do this

  1. Open notebooks/labs/L3_peg_risk.ipynb in Jupyter (same GitHub repo as the course site).
  2. Run All. If yfinance downloads USDT-USD, Q1 is that figure. If download fails, do not invent prices — screenshot Naranjo Stablecoins and Peg Risk, or use the labeled class-freezer figure the notebook still saves and say which you used.
  3. Edit the Q4 quotes to your A4 path and the Q5 thresholds if you want different numbers.
  4. Write Q1–Q5. Attach both PNGs.

Questions (20 points)

Q1 (4). When did that coin’s price leave 1.00 (or, for the freezer, what is each card really worth if everyone ran)? Largest absolute gap you report? Screenshot L3-depeg.png. Name the source.

Q2 (4). 5–7 sentences, class language: how a $1 peg is supposed to work (mint/redeem or a second market), and one friction that can stop that (weekend banking, redemption gate, doubt about reserves).

Q3 (4). Why a Terra/Luna-style design fails a different way than a reserve-backed token that cannot redeem on time. Not a news recap.

Q4 (4). Your team coin: is it trying to be 1-for-1 CLASSUSD, a voucher, or free-floating scrip? What would a “depeg” mean for you? Three dated quotes (from A4) → L3-ourcoin.png.

Q5 (4). Two kill criteria (if-then) you will paste into A6. They need a number or an operation (spread, depth, pause, wait time) — not “if we feel nervous.”

You will not

  • invent USDT prices when the download fails
  • write “we’ll watch the market” as a kill rule
  • paste the notebook scaffold as Q2/Q3 without rewriting
