Part 1 — Risk

Three risks we own

LabelWhat we sawMitigation we actually have

What we saw in class. Observer: when the class bowl was TEAM-poor, the next sip was worse than the start. Pause on Remix would stop transfers; it would not put more CLASSUSD in the jar.

Kill criteria (if-then with a number)

  1. IF \lvert P - 0.50\rvert / 0.50 > 0.40 AND CLASSUSD depth < 50 THEN pause transfers.
  2. IF a booked slot is not honored within 24 hours THEN stop mint and post the run (unhonored minutes / outstanding SPIN).
  3. IF the owner key might be leaked THEN pause and rotate using the A2 lost-key sentence.

“We’ll watch the market” is not a rule.
