Assurance question: what was recorded, what it is worth, and what an assurer can stand behind.

CLASSUSD = class unit of account · EAGE = team-coin example · Testnet only · Seed never

Course spine

  1. Money must pay, sit, and price.
  2. Money is a list; a payment is two updates.
  3. Hash = fingerprint · Signature = approval · Address = locker · Seed = house key (never).
  4. A chain: pages name prior fingerprints; publish costs a puzzle.
  5. “I have the coin” = wallet / ETF share / exchange tab.
  6. Issue a testnet coin vs CLASSUSD; say what an assurer can stand behind.

Coding lab (class patterns)

Python · hash fingerprint (S2)

import hashlib

def fingerprint(msg: str) -> str:
    return hashlib.sha256(msg.encode()).hexdigest()

print(fingerprint("Ava->Ben:2")[:12])
# Change one digit → totally new print (not “almost the same”).

Python · tiny PoW mine (S3)

def mine(prev, txs, zeros=3):
    nonce = 0
    while True:
        raw = f"{prev}|{txs}|{nonce}"
        h = fingerprint(raw)
        if h.startswith("0" * zeros):
            return nonce, h
        nonce += 1

Python · lemonade AMM (S8)

def buy_x(x, y, dx):
    k = x * y
    x2 = x - dx          # buyer takes dx of EAGE
    y2 = k / x2
    paid = y2 - y        # CLASSUSD paid in
    spot = y2 / x2
    return paid, spot

# buy_x(100, 100, 10) → (~11.11, ~1.2346)

Solidity-shaped · mint under a cap (S5)

mapping(address => uint256) bal;
uint256 public total;
uint256 public cap;
address public minter;

function mint(address to, uint256 n) public {
    require(msg.sender == minter);
    require(total + n <= cap);
    bal[to] += n;
    total += n;
}

Contract address = the asset; ticker = nickname. Testnet only.

Python · netting residual (S10)

def residual(edges):
    net = {}
    for a, b, amt in edges:
        net[a] = net.get(a, 0) - amt
        net[b] = net.get(b, 0) + amt
    return {k: v for k, v in net.items() if v}

# A→B 10, B→C 10, C→A 10 → {}
# A→B 15, B→C 10, C→A 10 → A still owes 5

Session cards

Each card: Def · Easy · Case · Mix-up · Assurer

S1 · Community money

Def. Money can spend now (pay), save for later (sit), and write prices (price). A ledger lists who has what. A payment updates two rows. Velocity = spent ÷ outstanding.

Easy. Punch = meal credit. Forget the kitchen credit = a burn, not a payment.

Case. Capitol Hill babysitting co-op (Sweeney & Sweeney; Krugman): too little scrip → hoarding → nobody sat — a pay-job failure. Sarafu (Kenya): local shops take a local unit when cash is tight.

Mix-up. “Digital ⇒ money.” Digital is a rail.

Assurer. Name pay, sit, or price for your coin.

S2 · Keys and wallets

Def. Hash fingerprints bytes. Signature authorizes a spend. Address is public. Seed is the private house key.

Easy. Hash detects tampering; it does not hide the bag. Self-custody = you hold the seed.

Case. Exchange-app balances are often an IOU — when the company fails, holders wait in line (unlike MetaMask with the seed). SHA-256: change one digit, the print does not “almost match.”

Mix-up. Hash = encryption. Seed in a homework PDF.

Assurer. Keys or broker receivable on the balance sheet?

S3 · Tiny chain

Def. A blockchain is a shared notebook: each page names the prior hash, and publishing requires costly proof of work. Verify rechecks zeros and parent links.

Easy. Difficulty = leading zeros (class: 3). Quiet edit without re-mine → PoW fails first.

Case. Bitcoin whitepaper (Nakamoto 2008): tamper-evidence by linkage + work. Quiet edit of “Ava→Ben:2” to “200” breaks zeros — same geometry as forging a closed invoice. Unbundle: EAGE needs balances + signatures + rented testnet, not a new L1.

Mix-up. Mining encrypts. One confirmation = Fedwire finality.

Assurer. Does the page still beep-test and point at the real prior page?

S4 · Markets and access

Def. Price = CLASSUSD per coin now. Index = playlist. Beta = sample co-movement (habit, not insurance). Wallet / ETF / exchange tab = three legal objects.

Easy. Airdrop = gift; sale = booth; earn = wage. Freeze before Remix.

Case. Risk desk: “When the S&P moves 1%, how hard did this name move?” Spot Bitcoin ETF: fund share + custodian. Exchange app: often a customer claim. Overnight test needs a use.

Mix-up. High beta = good buy. Listed = I hold it.

Assurer. Keys, fund share, or receivable?

S5 · Smart contracts

Def. Posted house rules plus shared state. ERC-20 standardizes buttons. Mint / cap / pause = issuer controls. Gas pays for the attempt; revert rolls state back.

Easy. “Smart” ≠ wise. Decide minter / pauser / cap before deploy.

Case. Vending machine / Monopoly banker: only the named role prints; the box lid is the cap. Failed snack still hummed — gas still spent.

Mix-up. Contract does “the right thing.” Lost pauser is fine.

Assurer. Who mints, and what stops runaway supply?

S6 · Deploy and airdrop

Def. Deploy bolts the machine to a network. The contract address is the asset identity; the ticker is a nickname. Cap: airdrop×people + pool + treasury ≤ cap.

Easy. Two tokens named EAGE with different addresses = two coins.

Case. Wrong-network / empty-faucet failures are normal ops. Auditors vouch the registry address and tx hashes — not a ticker screenshot.

Mix-up. Airdrop the first of two deploys.

Assurer. Which address on which network would you vouch?

S7 · Unit vs rail

Def. Unit of account = how you think the price. Rail = the pipe that moved value.

Easy. Hoodie = 8 CLASSUSD (unit); Ava paid 16 EAGE (rail).

Case. Remittance of $50: pain is ID, cash-out, weekends — not hash speed. Cookie $1.50 + campus-card tap = unit dollars, rail card.

Mix-up. Paid in crypto ⇒ priced in crypto.

Assurer. Separate yardstick from pipe in your log row.

S8 · Lemonade AMM

Def. AMM prices by x \times y = k. Spot = y/x. Average = this trade’s paid/size. Slippage = the gap. IL = jar vs hold (not a fee).

Easy. Start 100/100, k=10{,}000. Buy 10 → pay 11.11, spot 1.2346.

Case. Uniswap v2 (Adams et al. 2020): same constant-product geometry. A classmate not on your team must swap — real circulation.

Mix-up. Spot = average.

Assurer. Mark-to-market or realized cost after you moved the book?

S9 · Claims and DvP

Def. A token is the claim itself or a receipt for something off-chain. DvP = both legs or neither. Redemption = stub → coat.

Easy. On-chain ≠ backed.

Case. Warehouse receipt vs grain. Venmo-then-forgot-PDF is a trade fail, not DvP.

Mix-up. “On-chain so backed.”

Assurer. If the team disappears, what does the holder have?

S10 · Public money and netting

Def. Money flower (BIS): cash, deposits, CBDC, etc. are different petals. Netting cancels a cycle; settle the residual.

Easy. Your ERC-20 is not a CBDC. Equal $10 triangle → zeros; uneven 15 → leftover 5.

Case. BIS money-flower taxonomy. Lunch-table Venmo: three $10 IOUs erased = same economics, fewer wires.

Mix-up. Labeling a campus token “CBDC.”

Assurer. What still owes after netting?

S11 · Runs and depegs

Def. Peg = poster promise. Depeg = market leaves it. Run = simultaneous redemption. Kill rule = if-then with numbers.

Easy. Pause stops transfers; it does not refill the freezer.

Case. Terra–Luna (Liu, Makarov & Schoar 2023): run/depeg geometry. Class ice-cream: 10,000 cards / 200 scoops ⇒ full run = 0.02 scoops/card.

Mix-up. “We can pause, so no run.”

Assurer. Threshold + liquidity test + action you own?

S12 · If this left the lab

Def. Howey asks investment-contract facts — not the word “utility.” Travel Rule wants identity with the payment. Verdict: go / partner / pass.

Easy. Facts beat labels. Mainnet/public sale for class = project zero.

Case. SEC v. Howey (1946). Classroom Poster B (“buy tonight, 10×”) is Howey-shaped; Poster A (closed voucher) is not. FATF Travel Rule: name + account with the wire.

Mix-up. “Utility token” as a complete answer.

Assurer. Build, rent a licensed rail, or keep it in the lab?

S13 · Demo day

Def. Proof is live evidence in order — not a memo read aloud.

Order. (1) contract (2) stranger holds it (3) pool quote (4) transfer + redeem + hash (5) verdict.

Unbundle. Chain or DB? consensus or registrar? token or escrow?

Case. MIT “design of financial systems” question: which pieces did you actually need? An evidenced pass can be an A-level ending.

Mix-up. Memo theater instead of a stranger’s balance.

Assurer. What circulated — and what would you assure?

  2. A payment updates two rows.
  3. Hash detects tampering; it does not hide the bag.
  4. Seed = house key; address = locker.
  5. Quiet edits break zeros or parent links.
  6. Beta is a sample habit, not a seatbelt.
  7. Wallet ≠ ETF ≠ tab.

  9. Unit = think; rail = moved.
